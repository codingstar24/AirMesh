# Contributing to AirMesh

Thank you for your interest in contributing to **AirMesh**!

AirMesh is an open-source, 100% offline, privacy-first peer-to-peer file mesh created and architected by **Zohair Sathaliya**.

## Quick Links
- **Full Contribution Guidelines**: Please review [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md) for complete coding style, zero-unsafe, and testing mandates.
- **Architecture Overview**: See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
- **Security Policy**: See [docs/SECURITY.md](docs/SECURITY.md).

## Submitting Pull Requests
1. Fork the repository and create your feature branch: `git checkout -b feature/amazing-feature`.
2. Commit your changes: `git commit -m 'Add amazing feature'`.
3. Push to the branch: `git push origin feature/amazing-feature`.
4. Open a Pull Request.

All contributions must respect our **100% Offline & Zero Telemetry** core guarantee.
